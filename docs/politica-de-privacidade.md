# Política de Privacidade — NEOPAD

**Última atualização:** [preencher data]

O NEOPAD é um aplicativo de reprodução de música. Esta política explica o que acontece com os dados de quem usa o app.

## O que o NEOPAD armazena

- **Arquivos de música importados** (título, artista, capa e o próprio áudio): ficam guardados apenas no armazenamento local do aparelho do usuário, através do IndexedDB do navegador.
- **Curtidas e preferências** (faixas curtidas, volume, tema claro/escuro): guardadas localmente no aparelho via localStorage.

## O que o NEOPAD *não* faz

- Não envia arquivos de música, capas ou metadados para nenhum servidor.
- Não coleta dados pessoais, localização, contatos ou identificadores de publicidade.
- Não usa cookies de rastreamento nem compartilha dados com terceiros.
- Não exibe anúncios.

## Permissões do aparelho

O NEOPAD pode solicitar acesso a arquivos do aparelho apenas quando o usuário escolhe importar músicas. Nenhum outro dado é acessado.

## Armazenamento e remoção

Todos os dados descritos acima existem somente no aparelho do usuário. Desinstalar o aplicativo ou limpar os dados do app (nas configurações do Android) remove permanentemente essas informações. Não há cópia em nenhum servidor para ser apagada.
